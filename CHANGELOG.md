[CONTRIBUTING.md](CONTRIBUTING.md).

## 0.1.0

First version: typed configuration contracts for server-side Swift on
[swift-configuration](https://github.com/apple/swift-configuration), implementing spec `v1alpha1`. Tags have no `v`
prefix, as SwiftPM expects.

### Features

* A declaration with what swift-configuration lacks: descriptions, secrets, ranges, lengths, RE2 patterns, enums,
  URL schemes, list bounds (`itemMin`/`itemMax`) and file inputs (config files with a JSON Schema derived from a
  `Decodable` type, TLS key pairs, CA bundles, keystores, text and binary files).
* Boot validation that reports every problem at once with stable error codes and writes it to
  `/dev/termination-log`.
* Contract export, config-file overlays, contract-first mode and the shared conformance runner.
* The gateway and orders examples.
